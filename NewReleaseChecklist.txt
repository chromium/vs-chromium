When making a new release

Master branch
=============
See docs/release.md: bump the version (node tools/release/set-version.js
<version>), write docs/release-notes/<version>.md, build and test the packages
locally (tools/release/build-release.ps1), push the tag v<version>, review and
publish the draft GitHub release created by .github/workflows/release.yml.


gh-pages branch
===============

1. Update the "What's new" section in "index.html"

2. Update the file "latest_version.txt" with the new version # and new URL

    version: x.y.z
    url: https://github.com/chromium/vs-chromium/releases/tag/vx.y.z

3. Commit and push.
