# VsChromium 0.10.1

VsChromium 0.10.1 is a bug fix release for the Linux and macOS servers.

## Fixes

- **Linux and macOS: projects were never indexed.** The server rejected every ignore pattern
  containing `/` (e.g. `.git/`), because on Linux and macOS the alternate directory separator is
  the same as the directory separator. All the patterns are now normalized to the platform
  separator, in the configuration files and in search patterns. The VS Code extension on Linux and
  macOS (and the standalone Linux and macOS servers) of 0.10.0 are affected; Windows is not.
- **Linux: inotify watch limit.** When the user limit of inotify watches
  (`fs.inotify.max_user_watches`) is reached, the server now switches to periodic rescans as
  intended, instead of retrying to start the file system watchers.
- **File system watchers** are fully stopped and released when they stop or fail to start.

## Diagnostics

- New `DirectoryWatcherStart` operation timing in the server statistics: the time to start the file
  system watchers of new projects (one inotify watch per directory on Linux).
